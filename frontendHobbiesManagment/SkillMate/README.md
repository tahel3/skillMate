# SkillMate – Frontend

React 19 + Vite client for SkillMate. See the [main README](../../README.md) for the full project overview.

**Stack:** React, Redux Toolkit + RTK Query, React Router, Material UI (MUI), React Hook Form, STOMP over SockJS (real-time chat).

```bash
npm install
npm run dev      # http://localhost:5173
```

The backend must be running on `http://localhost:8080`.
